== 👋 Wstęp

Ten dokument pokazuje funkcje, których *Markdown nie obsługuje lub obsługuje słabo*.

== 📚 Spis treści (TOC)

NOTE: Ten spis treści powstał automatycznie dzięki `:toc:` (Markdown tego NIE ma bez pluginów).

== ⚠️ Bloki specjalne (brak w Markdown)

TIP: To jest wskazówka (Markdown nie ma natywnych bloków TIP).

WARNING: To jest ostrzeżenie (w Markdown trzeba kombinować z emoji lub cytatem).

IMPORTANT: To jest ważna informacja z semantyką.

== 🧾 Metadane dokumentu

NOTE: Autor i tytuł na górze pliku to część składni AsciiDoc (Markdown tego nie wspiera).

== 📋 Zaawansowana tabela

[cols="1,2", options="header"]
|===
| Nazwa | Opis

| A
| Możemy kontrolować szerokość kolumn

| B
| Możliwe są bardziej zaawansowane opcje niż w Markdown
|===

NOTE: Markdown ma bardzo ograniczone tabele (brak stylów, colspan itd.).

== 💻 Blok kodu z opcjami

[source,python]
----
def hello():
    print("Hello, world!")
----

NOTE: W AsciiDoc można dodać opcje (np. numerowanie linii). Markdown tego nie wspiera natywnie.

== 🖼️ Obraz z kontrolą

image::https://via.placeholder.com/150[Przykład, width=100]

NOTE: Możemy ustawić np. szerokość — w Markdown brak takich opcji.

== 🔽 Zagnieżdżone listy (bardziej czytelne)

* Element 1
** Pod-element 1.1
*** Pod-element 1.1.1

NOTE: W Markdown zagnieżdżenia zależą od spacji i często się psują.

== 🔗 Podsumowanie

IMPORTANT: AsciiDoc (np. przez Asciidoctor) to bardziej zaawansowany system dokumentacji niż Markdown.

* Markdown → prosty, szybki
* AsciiDoc → bardziej rozbudowany i konfigurowalny
